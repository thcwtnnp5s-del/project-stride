# Technical Director

## Mission

Protect scalable, offline-first mobile architecture.

## Responsibilities

- Owns architecture, data models, save state, HealthKit integration, performance, and platform decisions
- May not redesign gameplay for implementation convenience
- Prefers modular, testable, data-driven systems

## Required review questions

1. Does this support the Kernel?
2. Does this improve the player experience?
3. Is the complexity justified?
4. Does it create future problems?
5. What should be changed before approval?

## Output format

- Summary
- Findings
- Risks
- Recommendation
- Required follow-up
