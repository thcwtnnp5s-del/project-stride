# Pixel UI content — v1

Provenance and native sizes for every file in this directory. Declared file by
file in `pubspec.yaml`; an undeclared file here is an asset that does not exist.

Every one is drawn through `lib/ui/components/pixel_asset.dart`, at an exact
integer multiple of the native size below, with nearest-neighbour filtering and
no smoothing (`ART_DIRECTION.md` **L-18**). **The native size is declared in the
widget, not encoded in the filename**, and there are deliberately no `2.0x/` or
`3.0x/` variant directories.

## The two files that need explaining

### `item_unknown.png` — the placeholder, authored for Phase 1

Generated by `GAME_BIBLE/ART/exploration/WALKSCAPE_PIVOT_01/gen_placeholder.js`.

Shown for any item the icon set does not cover. **Deliberately
non-representational**: two colours, a rim, and nothing inside. No aperture, no
centred mark, no frame ring.

That constraint is not aesthetic. A small element centred inside a darker frame
is chrome grammar, and chrome grammar is what made the Hollow Sigil read as a
padlock, an equipment slot, a disabled cell, and a coin across five attempts —
four systems Stride does not have. This icon appears in the grid cell most likely
to be misread, so it asserts nothing at all.

It should look unfinished, because it is.

### `portrait_traveler.png` — TEMPORARY, and replaceable

**The character portrait workstream is PAUSED with no approved asset and no
approved canvas.** `GAME_BIBLE/ART/exploration/CHARACTER_PORTRAIT_CLOSEOUT.md`
governs it, and its §6 lists what a future restart must **not** inherit —
including this face's geometry.

This file is evidence from a failed round, used because a frame needs something
in it. Nothing about any layout depends on its content: the frame is a component
(`InsetWell`), the image is an asset, and swapping the one path in
`lib/ui/icons/pixel_icons.dart` is the entire migration.

## Icons deliberately NOT shipped

The rest of the Round 04 item set is absent, not forgotten. Four icons in it
still produce confident wrong nouns at play scale — Pine Log reads as coins, Oak
Handle as a backpack, Hollow Root as a pelt, Bronze Ingot as gold bullion
(`ICON_REPAIR_04.md` §9). Scoping this directory to the items a Phase 1 player
can actually hold means that unresolved question blocks nothing here.
