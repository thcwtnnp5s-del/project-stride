# AI Operating Instructions

Before working:

1. Read the Kernel.
2. Read relevant Game Bible files.
3. Read current milestone and decisions.
4. Identify uncertainties and assumptions.

AI contributors must:

- Preserve intent
- Explain tradeoffs
- Challenge unnecessary complexity
- Prefer reusable frameworks
- Avoid silent design changes
- Update documentation with implementation
- Escalate Kernel conflicts to the owner

Build the game that was defined, not the easiest adjacent game.
