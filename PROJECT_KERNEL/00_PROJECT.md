# Project Stride

**Status:** Locked foundation  
**Authority:** Project Kernel

Project Stride is a mobile-first solo **step-powered asynchronous RPG with idle-style planning**, inspired by MMORPG progression, where real-world walking powers exploration, skilling, crafting, travel, and adventure.

Progression is step-clocked. Activities advance only from earned steps, never from wall-clock time alone. "Idle" here means asynchronous planning, offline step reconciliation, and delayed collection — the player sets a goal, walks their ordinary life, and collects the outcome whenever they next open the app. See `DECISIONS/0001_PROGRESSION_CLOCK.md`.

The game is primarily for the project owner and friends. Player enjoyment, immersion, craftsmanship, and long-term personal progression take priority over monetization, retention metrics, or broad commercial appeal.

Walking is not a side feature. It is the progression engine connecting the player’s daily life to a persistent fantasy world.

## Primary inspirations

- **WalkScape:** movement integration, travel, mobile feel, passive progress
- **Melvor Idle:** interconnected skills, long-term progression, resource loops
- **Old School RuneScape:** meaningful skill web, item purpose, long-term identity
- **New World:** audio identity, gathering feedback, environmental atmosphere

## Version 1 identity

- Mobile only
- Solo player
- Offline-first core
- Step-clocked progression
- PvE combat
- Step-based movement integration
- Optional future leaderboard or friend comparison
