# Decision Framework

Evaluate every major feature against:

1. Does it strengthen the fantasy that real-world movement powers adventure?
2. Does it create a meaningful choice?
3. Does it connect to existing systems?
4. Does it respect short and long player sessions?
5. Does it improve enjoyment, immersion, curiosity, or satisfaction?
6. Can it support future expansion?
7. Is the added complexity worth the player value?

A smaller coherent game is better than a larger confused game.
