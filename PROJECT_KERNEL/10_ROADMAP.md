# Roadmap

## Milestone 0 — Foundation

Repository, kernel, Game Bible, agent roles, workflows, and technical planning.

## Milestone 1 — First Adventure

One complete vertical slice containing step integration, travel, gathering, crafting, inventory, equipment, PvE combat, save state, UX, audio, and starter content.

## Milestone 2 — Core-system expansion

Deepen skills, crafting, equipment, quests, encounters, and progression.

## Milestone 3 — World expansion

Add more regions, enemies, materials, lore, bosses, and advanced progression.

## Milestone 4 — Optional social layer

Consider leaderboards, friend comparisons, cloud save, and shared achievements without compromising solo play.
