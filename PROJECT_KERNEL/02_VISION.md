# Project Stride Vision

Project Stride is a mobile-first solo RPG where real-world movement powers a persistent personal adventure.

The player builds a character over months and years through:

- Skills
- Equipment
- Crafting
- Exploration
- Quests
- PvE encounters
- Boss progression
- World discovery

The goal is to recreate the emotional experience of an MMORPG character without requiring an MMO server.

The long-term ideal is:

> I built this character alongside my real life.
