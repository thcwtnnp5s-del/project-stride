# Non-Negotiables

- Mobile-first experience
- Initial iOS focus
- Solo RPG foundation
- PvE-focused active combat
- Walking is a foundational progression engine
- Offline-first core gameplay
- No FOMO
- No punishment for inactivity
- Audio is a first-class system
- Long-term expandable progression
- Data-driven content where practical
- The core game must not require constant internet connectivity
