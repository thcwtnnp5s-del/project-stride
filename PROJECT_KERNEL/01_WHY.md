# Why Project Stride Exists

Project Stride exists because real-world movement should feel like an adventure.

The game should transform ordinary walking into meaningful progress inside a persistent fantasy world.

A walk should become:

- A journey completed
- A resource expedition
- A region discovered
- A character strengthened
- A future encounter unlocked

The emotional target is:

> I was already going to take that walk. Now it meant something.

The game should fit the player’s life instead of demanding that the player organize life around the game.
