# Skill System Framework

## Initial categories

### Gathering

- Woodcutting
- Mining
- Foraging

### Production

- Smithing
- Cooking
- General Crafting — **Milestone 02+, not in the vertical slice**

### Combat progression

**No combat skills in Milestone 01.** Combat power comes from character level and equipment only. Weapon mastery is deferred to Milestone 02. See `DECISIONS/0003_COMBAT_MODEL.md`.

## Milestone 01 skill set — frozen

Exactly five skills: **Woodcutting, Mining, Foraging, Smithing, Cooking.** Level cap 20. Adding a sixth requires a new decision record. See `DECISIONS/0004_MILESTONE_01_SCOPE.md`.

## Every skill needs

- Clear fantasy
- XP source
- Level curve
- Unlock cadence
- Connected resource outputs
- Connected consuming systems
- Milestone rewards
- Future expansion path

Skills should not exist only to increase a number.
