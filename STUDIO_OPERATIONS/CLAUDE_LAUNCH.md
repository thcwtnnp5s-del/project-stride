# Claude Code Launch Protocol

## Phase 1 — Read

Read:

- `CLAUDE.md`
- `PROJECT_STATE.md`
- `PROJECT_KERNEL/`
- `STUDIO_OPERATIONS/`
- `AGENTS/`
- `GAME_BIBLE/`
- `MILESTONES/`

## Phase 2 — Audit

Create `STUDIO_INITIALIZATION_REPORT.md` containing:

- Confirmed understanding
- Contradictions
- Missing decisions
- Technical unknowns
- Recommended next action

## Phase 3 — Assemble agents

Initialize the defined leadership, specialist, and review roles.

## Phase 4 — Plan before coding

Create:

- `ARCHITECTURE_IMPLEMENTATION_PLAN.md`
- `MILESTONES/MILESTONE_01_TASK_BREAKDOWN.md`

Run design, critic, QA, and technical review.

## Phase 5 — Wait for approval

Do not start broad implementation until the owner approves the reviewed plans.
